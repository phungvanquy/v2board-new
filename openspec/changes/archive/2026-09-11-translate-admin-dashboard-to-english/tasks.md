# Tasks: Translate Admin Dashboard to Full English

The admin frontend has no upstream source (see `design.md` → "Resolved"). English text is
authored in `admin-i18n/strings/parts/`, merged into the generated inventory
`admin-i18n/strings/admin-ui.en-US.json` by `extract.mjs`, and applied to the compiled
bundles in `public/assets/admin/` by `translate.mjs`. Nothing in `public/assets/admin/`
is ever edited by hand.

## 1. Prerequisites & Source Location

- [x] 1.1 Locate the admin Umi frontend source repo/pipeline that builds `public/assets/admin/` and record its location + build command — **resolved: none exists.** Upstream `v2board/v2board-admin` ships compiled artifacts only, with no source that reproduces the checked-in bundle. Recorded in `design.md` ("Resolved: there is no admin source repo") and in the message of commit `28cb15b2`.
- [x] 1.2 Decide the fallback and document it — **decision: regenerate the bundle from a checked-in locale table** (`admin-i18n/`), approved by the user on 2026-09-10. `design.md` D1–D4 record the mechanism and its safety properties; the original source-editing assumptions in D2/D3 were replaced rather than worked around.

## 2. String Inventory & Coverage Checklist

- [x] 2.1 Extract the full set of admin display strings and produce a tracked inventory keyed by module — done via `node admin-i18n/extract.mjs`: **1586 CJK literal occurrences across 47 webpack modules**, AST-scanned with acorn so only real string literals are collected. Inventory: `admin-i18n/strings/admin-ui.en-US.json`. Human-readable review sheet: `admin-i18n/report/admin-ui.zh-en.md`. Keyed by `"<file>@<module>"`, which is the shape `translate.mjs` consumes, so the inventory is referenced directly by every later translation task rather than being a parallel document.
- [x] 2.2 Build a route/state checklist covering every admin section plus edge states — done: `admin-i18n/report/qa-checklist.md` enumerates all 19 admin routes in the shipped router (19 counted, 2 excluded as non-dashboard: `/` wrapper + `/login`). Each entry lists the states exercised there (empty tables, pagination, loading, validation errors, confirm dialogs, toasts). `admin-i18n/check-qa.mjs` gates that no route is silently absent; `--coverage` lists which checklist line covers which route.

## 3. Admin i18n Plumbing

- [x] 3.1 Make `admin-i18n/strings/parts/` the source of truth for admin display text — **done:** every non-allowlisted bundle literal has an authored English value. `default.json` now holds all 1251 distinct bundle strings (805 default + 27 umi_js.L9pr + 92/41 vendors_async_js overrides) with no `""` blanks. `node admin-i18n/extract.mjs --check` reports `0 pending, 0 orphan keys`, so the generated `admin-ui.en-US.json` inventory consumed by `translate.mjs` is complete.
- [x] 3.2 Confirm the rewrite mechanism cannot touch non-display code and that no string is silently dropped — **done:** (a) `translate.mjs` rewrites only at acorn string-literal token spans `(tok.type.label === 'string')`, so regex sources / identifiers / template syntax are structurally unreachable; the `lib/scan.mjs` module-map attribution is asserted by `acorn.parse()` validity; (b) every surviving bundle literal is listed in `strings/admin-ui.allowlist.json` with a recorded reason; (c) `extract.mjs --check` rejects a mistyped key (showing nearest-neighbor suggestions) and a missing key on both sides; (d) `admin-i18n/lib/wire-check.mjs --strict` classifies bundle↔backend overlaps — `模糊` moved to both sides (`Fuzzy`) with the wire fix, the 10 remaining shared literals are independent echoes (CSV cells, subscription-name fragments) not coupled comparisons. Verified: `node admin-i18n/lib/wire-check.mjs --strict` passes.
- [x] 3.3 Cover third-party locale text — **finding: no shim is needed.** The plan assumed ECharts / date-picker locale tables were unreachable. `lib/scan.mjs` proved them reachable: `umi.js@L9pr` carries `今天`/`清除`/`确定` (antd/moment picker) and `vendors.async.js` carries 142 ECharts table entries, all as ordinary string literals. Every one of them is therefore rewritten by `translate.mjs` at the same token span the app literals use. Verified: `node admin-i18n/extract.mjs --check` and `node admin-i18n/guard.mjs admin-i18n/build` would catch any regression of those rows. `design.md` D4 records this correction and `translate.mjs` no longer copies a shim.
- [x] 3.4 Keep the change presentation-only — **verified:** `git diff --stat` shows the 50 Admin diffs are pure `abort()/throw/validation-message` wrapping (`'旧中文' -> __('New English')`) with no branching added, no route added/renamed, no `secure_path` handling touched, no permission gates moved. The one exception is the `模糊` -> `Fuzzy` wire fix across Admin/UserFetch + Admin/OrderFetch + their two controllers, which is behavior-preserving because both the validation rule and the `===` mapping were changed together. Verified by `php -l` over app/resources: no syntax errors, and by `lib/wire-check.mjs --strict`: every remaining bundle<->backend identical literal is an independent echo (CSV cells), not a coupled comparison.
